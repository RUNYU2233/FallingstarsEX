## 🚀 快速部署

### 2.1 核心库安装（二选一）

将选中的文件重命名为 `FallingStars.dll`，放置于游戏根目录（`gamemd.exe` 同级）：

- **稳定版（`_Stable`）**：静默运行，仅启动时输出一条欢迎日志。→ **推荐玩家或正式游玩使用**
- **调试版（`_Debug`）**：生成 `FallingStars.log` 完整流水日志，启动时弹出版本提示窗。→ **推荐内部测试使用，如若无问题，可以使用稳定版**

### 2.2 FA2sp 编辑器数据注入

1. 将 `FAData_TriggerAndScript.ini` 合并至 FA2sp 数据目录中的同名文件。
2. **保存编码要求**：根据语言写入即可，无特殊要求
3. 重启 FA2sp 使配置生效。

## ⚙️ 触发动作（结果）API

### 3.1 动作 520 —— 单位种类计数器

右下角黑底显示指定大类单位实时数量，文本颜色自动适配触发方阵营色。

| 参数 | 取值/说明 |
| :--- | :--- |
| **P1** | CSF文本选择 |
| **P2** | 指定外交关系 |
| **P3** | P2指定的所属方（只有P2=5时成立） |
| **P4**|  `0`全部 / `1`载具 / `2`步兵 / `3`飞行器 / `4`建筑 / `5`海军 |

> 该计数器激活时，右下角超级武器倒计时等系统文本将自动上移避让。

---

### 3.2 动作 521 —— 精确科技类型计数器

逻辑同 520，但统计对象为特定的 `[TechType]` 注册名（如 `GDIAPC`）。

| 参数 | 说明 |
| :--- | :--- |
| **P1** | CSF文本选择 |
| **P2** | 指定外交关系 |
| **P3** | P2指定的所属方（只有P2=5时成立） |
| **P4** | 关键：科技类型内部注册名（`Rules.ini` 中的条目） |

---

### 3.3 动作 526 —— 富文本彩色字幕

与`触发动作11相同`，颜色由特定符号指定。

**颜色参数映射：**

| 参数 | 作用域 |
| :--- | :--- |
| **P2** | `()`包裹内容 |
| **P3** | `<>`包裹内容 |
| **P4** | `[]`包裹内容 |
| **默认** | 无符号时或未被符号括起的内容 → 白色 |

**语法示例：**
```

(警告！)<小心>[危险]任务完成
↑P3色   ↑P4色 ↑P5色  ↑白色

```

> 多条字幕堆叠时自动垂直排列，互不遮挡。

## 🧩 触发事件（条件）API

**事件 607 / 608 / 609 —— 数量阈值判定**

统计对象固定为 **触发方当前存活单位**。

| 事件 ID | 逻辑 |
| :--- | :--- |
| **607** | 数量 **等于** N |
| **608** | 数量 **大于** N |
| **609** | 数量 **小于** N |

**参数定义：**

- **P1**：单位种类（`0`全部 / `1`载具 / `2`步兵 / `3`飞行器 / `4`舰船 / `5`建筑）
- **P2**：比较阈值（整数）
